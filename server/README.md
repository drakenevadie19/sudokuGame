# Back-end for Sudoku Game
<h1>Links</h1>
<a  href="https://github.com/drakenevadie19/sudokuGameBackEnd.git" target="_blank" rel="noreferrer">Sudoku Game Back-end Repository</a>

<h1 style="margin-top: 20px;">Overall</h1>
<ul>
    <li>Implements RESTful APIs using <strong>Spring Boot</strong> and the <strong>MVC architecture</strong> for clean code separation.</li>
    <li>Uses <strong>Spring Data JPA</strong> to interact with a <strong>PostgreSQL</strong> database for persistent storage of user profiles and Sudoku history.</li>
    <li>Applies <strong>Spring Security with JWT authentication</strong> to manage secure user login and session handling.</li>
    <li>Integrates <strong>Apache Kafka (or RabbitMQ)</strong> to handle real-time events such as friend battles, notifications, and gameplay activity logs.</li>
    <li>Utilizes input validation and exception handling to ensure robust and safe API behavior.</li>
    <li>Supports JSON-based communication between the Angular front-end and the back-end APIs.</li>
</ul>

<h1 style="margin-top: 20px;">Technologies</h1>
<ul>
    <li><strong>Programming Languages:</strong> Java</li>
    <li><strong>Back-end Framework:</strong> Spring Boot (RESTful APIs using MVC Architecture)</li>
    <li><strong>Database:</strong> PostgreSQL (for storing user profiles and gameplay records)</li>
    <li><strong>Messaging System:</strong> Apache Kafka or RabbitMQ (for real-time event handling such as battles, notifications)</li>
    <li><strong>Security:</strong> Spring Security with JWT (for user authentication and authorization)</li>
    <li><strong>API Communication:</strong> JSON over HTTP (REST APIs)</li>
    <li><strong>DevOps and hosting:</strong> Docker, Render </li>
</ul>
